# ODAM Frontend

Frontend React + Vite del sistema de gestión odontológica ODAM.

## Estructura

`src/app/pages` contiene las pantallas por dominio; `components/ui` conserva los componentes reutilizables existentes; `layouts`, `routes`, `hooks`, `types` y `api` separan responsabilidades.

Los componentes del prototipo anterior se conservan en `src/app/components/legacy` para no perder código ni funcionalidades durante la migración.
